rocket_launchPrimeros pasos

Esta herramienta obtiene los comentarios de una publicación de Facebook o Instagram, los analiza y te permite copiarlos o exportarlos. Todo ocurre en tu navegador.

  1. Elige la red social y un método en la sección Obtener: conectar con la API, usar el extractor de navegador o importar un archivo. Si pegas un enlace, la red social se detecta sola.
  2. Obtén los comentarios siguiendo los pasos numerados de cada método.
  3. Revisa el resumen: autores más activos, actividad en el tiempo, sentimiento, palabras y emojis frecuentes.
  4. Filtra y busca en la pestaña Comentarios.
  5. Copia o exporta a Excel, CSV, JSON, texto o informe HTML.

verified_userConectar con Facebook

1. Crear la app (una sola vez)

  1. Entra en developers.facebook.com/apps y pulsa Crear app. Elige el caso de uso para administrar páginas (o el tipo Empresa).
  2. Agrega el producto Inicio de sesión con Facebook (o Facebook Login for Business).
  3. En su configuración activa Inicio de sesión con el SDK de JavaScript y agrega tu dominio en Dominios permitidos para el SDK de JavaScript. localhost está permitido en modo desarrollo.
  4. En Configuración → Básica copia el App ID y pégalo en el paso 1.
  5. Si usas Login for Business, crea una configuración con los permisos de abajo y pega su Configuration ID.

2. Permisos que se solicitan

  • pages_show_list: ver la lista de páginas que administras.
  • pages_read_engagement: leer publicaciones y métricas.
  • pages_read_user_content: leer los comentarios de los usuarios.

Mientras la app esté en modo desarrollo, solo pueden iniciar sesión sus administradores, desarrolladores y testers, sin necesidad de revisión. Para que la use cualquier persona, Meta exige la App Review.

3. Dónde abrir la página

Facebook solo permite iniciar sesión desde https:// o http://localhost. Para probar en tu equipo:

python3 -m http.server 8000 → abre http://localhost:8000

Sobre el token

Al elegir una página se genera su token de acceso automáticamente. Dura alrededor de 1–2 horas; después vuelve a iniciar sesión. El token nunca se guarda de forma permanente.

photo_cameraInstagram

Puedes analizar comentarios de Instagram con la API oficial (tus cuentas profesionales) o con el extractor (cualquier publicación que puedas ver). Elige Instagram en Obtener o pega directamente un enlace instagram.com/p/… o /reel/….

Requisitos para la API

  • Una cuenta profesional de Instagram (Empresa o Creador) vinculada a una página de Facebook que administres. Se vincula desde la configuración de la página o desde la app de Instagram (Configuración → Centro de cuentas).
  • La misma app de Meta que usas para Facebook, con el caso de uso o producto de Instagram añadido (API de Instagram con inicio de sesión de Facebook).
  • Permisos adicionales: instagram_basic (ver tus cuentas y publicaciones) e instagram_manage_comments (leer sus comentarios). Solo se piden cuando eliges Instagram.

Usar la API

  1. Elige Instagram y el método Conectar con Instagram.
  2. Pulsa Continuar con Facebook. Si ya tenías la sesión iniciada para Facebook, pulsa Conceder acceso a Instagram.
  3. Elige tu cuenta de Instagram y la publicación de la lista. También puedes pegar su URL: se busca entre las publicaciones recientes de tus cuentas.

Se obtienen el usuario, el texto, la fecha exacta, los me gusta y las respuestas de cada comentario. La API no proporciona la foto de perfil de quien comenta.

Usar el extractor

  1. Abre la publicación en instagram.com, en su propia página (no desde el feed).
  2. Pulsa el marcador Social Comments Analyzer: es el mismo que en Facebook y detecta solo en qué red estás.
  3. El extractor pulsa por ti “Ver respuestas” y “Cargar más comentarios”. Al terminar, copia el JSON y pégalo en la app.

En Instagram las fechas son exactas, porque la página incluye la fecha completa de cada comentario. La descripción de la publicación no se cuenta como comentario; se usa como título.

Límites y uso responsable

  • La API solo da acceso a publicaciones de tus cuentas profesionales; para las demás usa el extractor.
  • Las condiciones de uso de Instagram limitan la recogida automatizada de datos. Usa el extractor para publicaciones concretas que puedas ver, sin automatizarlo de forma masiva, y trata los datos según la normativa de protección de datos.
  • Si Instagram cambia el diseño de su web, puede que algunos datos dejen de detectarse con el extractor.

travel_exploreExtractor de navegador

Es un pequeño script que se ejecuta dentro de la pestaña de Facebook o Instagram, donde ya tienes la sesión iniciada (para Instagram, consulta también Usar el extractor en Instagram). Abre los comentarios ocultos, lee los que están en pantalla y genera un JSON.

Con el marcador (recomendado)

  1. Muestra la barra de marcadores (Ctrl+Shift+B).
  2. Arrastra el botón azul Social Comments Analyzer hasta la barra.
  3. Abre la publicación, elige Todos los comentarios y pulsa el marcador.
  4. Espera a que termine (puedes pulsar Detener y extraer) y pulsa Copiar JSON.

Con la consola

Pulsa F12 → Console, pega el código y pulsa Enter. Chrome puede pedirte escribir allow pasting la primera vez.

Consejos

  • Abre la publicación en su propia página o ventana, no desde el feed.
  • Las publicaciones con miles de comentarios pueden tardar varios minutos.
  • Facebook muestra fechas relativas (“3 h”, “2 sem”). Se convierten en fechas aproximadas, marcadas con ≈.
  • Si Facebook cambia su diseño, puede que algunos datos no se detecten.

upload_fileImportar archivos

Formatos admitidos:

  • JSON del extractor o un JSON exportado desde esta aplicación.
  • Respuesta de la Graph API ({"data":[…]}).
  • Arreglo JSON genérico de objetos.
  • CSV / TSV con encabezados. Se detecta el separador (coma, punto y coma o tabulador).

Columnas reconocidas automáticamente (en español o inglés): autor/author/name, texto/text/message/comment, fecha/date/created_time/timestamp, reacciones/likes, respuestas/replies, id, parent_id, url.

insightsEntender el análisis

  • Comentarios / Respuestas: los comentarios principales y las respuestas a ellos.
  • Autores únicos: personas distintas que comentaron.
  • Periodo: tiempo entre el primer y el último comentario.
  • Comentarios en el tiempo y actividad por hora: se agrupan por hora (si abarcan menos de 2 días), por día o por semana. Con el extractor las fechas son aproximadas (≈), y la actividad por hora solo se muestra si hay precisión horaria.
  • Autores más activos: quienes más comentaron. Pulsa un nombre para ver solo sus comentarios.
  • Sentimiento estimado: se calcula con un diccionario de palabras y emojis positivos y negativos (español e inglés), teniendo en cuenta negaciones como “no”. Es orientativo: no detecta ironía ni sarcasmo.
  • Palabras frecuentes: excluye palabras vacías (“de”, “que”, “the”…). Pulsa una para filtrar los comentarios que la contienen.
  • Emojis, hashtags y menciones: los más usados. Pulsa cualquiera para filtrar los comentarios que lo contienen.

filter_listBuscar y filtrar

  • Escribe en el buscador para filtrar por texto o autor. Usa autor:"Nombre Apellido" para un autor concreto.
  • Los chips de filtro se combinan entre grupos: por ejemplo Respuestas + Negativos.
  • La vista Conversación muestra los comentarios como en Facebook: burbujas con avatar, reacciones y respuestas anidadas. Los hilos se muestran desplegados; pulsa “Ocultar respuestas” para plegar uno, o usa Expandir todo / Contraer todo.
  • Con el extractor, la jerarquía se reconstruye a partir de la sangría con la que Facebook muestra las respuestas. Si importas un JSON de una versión anterior del extractor, se deduce del orden: cada respuesta pertenece al comentario que la precede.
  • La vista Tabla muestra todos los campos en columnas. Agrupar hilos coloca cada respuesta debajo de su comentario.
  • Pulsa los encabezados de la tabla para ordenar.
  • Marca filas para trabajar solo con esas: copiar y exportar usarán la selección.
  • Haz doble clic en una fila (o pulsa info) para ver todos sus datos.

ios_shareCopiar y exportar

Se exportan los comentarios seleccionados, o si no hay selección, todos los filtrados.

  • Copiar como tabla: pégalo directamente en Excel o Google Sheets.
  • Excel (.xlsx): incluye la hoja Comentarios con todos los campos y la hoja Resumen.
  • CSV: en UTF-8, compatible con Excel (los acentos y emojis se mantienen).
  • JSON: se puede volver a importar en esta aplicación.
  • Informe HTML: un documento listo para compartir o imprimir.

shieldPrivacidad y datos

  • Esta aplicación no tiene servidor: los comentarios se procesan y guardan solo en tu navegador.
  • Se guardan en el navegador: los últimos comentarios analizados, el App ID, el tema y tus preferencias (como no volver a ver el tutorial).
  • El token de Facebook solo se conserva si lo pides, y únicamente mientras la pestaña esté abierta.
  • Puedes borrarlo todo desde ⋮ → Restablecer preferencias y Resultados → ⋮ → Borrar estos datos.
  • Usa los datos de forma responsable y conforme a las condiciones de Facebook y a la normativa de protección de datos aplicable.

quizProblemas frecuentes

El botón “Continuar con Facebook” no hace nada
Comprueba que abres la página desde https:// o http://localhost, que el App ID es correcto y que el dominio está en “Dominios permitidos para el SDK de JavaScript”. Los bloqueadores de anuncios pueden impedir que se cargue el SDK de Facebook. Si el navegador bloqueó la ventana emergente, vuelve a pulsar el botón.
“No se encontraron páginas”
En el diálogo de Facebook, pulsa Editar acceso y marca las páginas que quieres usar. Debes tener un rol en la página que permita moderar o crear contenido.
Los comentarios salen sin nombre de autor
Facebook solo devuelve el autor si usas el token de la página dueña de la publicación con el permiso pages_read_user_content. Con el extractor, el autor se obtiene de lo que se ve en pantalla.
El extractor encuentra menos comentarios de los esperados
Elige “Todos los comentarios” en lugar de “Más relevantes” antes de ejecutarlo y deja que termine. Algunos comentarios pueden estar ocultos o eliminados, o no ser visibles para tu cuenta.
“Error validating access token” o “Session has expired”
El token caducó. Cierra sesión y vuelve a pulsar Continuar con Facebook.
Las URLs con “pfbid” no se reconocen
Con la sesión iniciada, usa Ver publicaciones y elige la publicación de la lista. Así no hace falta la URL.
No aparece mi cuenta de Instagram
La cuenta debe ser profesional (Empresa o Creador) y estar vinculada a una página de Facebook que administres. Al iniciar sesión, en la ventana de Facebook pulsa Editar acceso y marca tanto la página como la cuenta de Instagram. Si lo cambiaste después, cierra sesión y vuelve a entrar.
Error de permisos al leer comentarios de Instagram
Pulsa Conceder acceso a Instagram y acepta instagram_basic e instagram_manage_comments. Comprueba que tu app de Meta tiene añadido el caso de uso de Instagram y que tu usuario tiene un rol en la app mientras esté en modo desarrollo.
El Excel no se descarga
La exportación a Excel carga una librería desde internet. Sin conexión se descargará un CSV, que Excel también abre.
